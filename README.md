# imersao-dados-python-alura
# Dashboard de Salários na Área de Dados

Projeto desenvolvido durante a Imersão Dados com Python da Alura.

## Tecnologias utilizadas

* Python
* Pandas
* Streamlit
* Plotly

## Funcionalidades

* Filtros por ano, senioridade, tipo de contrato e tamanho da empresa
* Exibição de métricas salariais
* Visualização dos cargos com maiores salários médios
* Distribuição salarial por faixa de renda
* Proporção dos tipos de trabalho
* Mapa interativo com salários médios de Cientistas de Dados por país
* Tabela detalhada para exploração dos dados

## Objetivo

Desenvolver um dashboard interativo para análise de dados salariais na área de tecnologia, aplicando conceitos de manipulação de dados, visualização de informações e construção de aplicações com Streamlit.

## Tecnologias e bibliotecas

* Pandas
* Streamlit
* Plotly Express
